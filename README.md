## 📖 Sobre o projeto

Este é um site de fã clube criado em grupo pela turma de CY2 como projeto de estudo de desenvolvimento web. A ideia é reunir em uma página o que os fãs mais gostam, com um visual próprio e responsivo.

## 🛠️ Tecnologias

- **HTML5** para a estrutura das páginas
- **CSS3** para a estilização, com **Flexbox** e **Grid** no layout
- **JavaScript** para a interatividade

## 📁 Estrutura do repositório

| Arquivo | Descrição |
| --- | --- |
| `index.html` | Página principal do site |
| `style.css` | Estilos da página |

## 👀 Como visualizar

Por ser um site estático, basta abrir o arquivo `index.html` em qualquer navegador.
